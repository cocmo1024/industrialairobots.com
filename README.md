# industrialairobots.com

Independent, source-cited reference for industrial robots, cobots and humanoids — spec database, comparisons and engineering calculators.

```bash
npm install
npm run dev       # http://localhost:4321
npm run verify    # tests + type check + build + site checks
```

Static output in `dist/`, served by Cloudflare (push to `main` deploys). See `AGENTS.md`, `docs/STRATEGY.md`, `CONTENT_UPDATE_GUIDE.md`.
